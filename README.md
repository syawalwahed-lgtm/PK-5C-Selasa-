# LUMBA KERETA — Pendidikan Kesihatan Tahun 5: Penyakit

Modul web interaktif responsif untuk pembelajaran dan kuiz arcade.

## Kandungan
- Nota ringkas empat penyakit: demam campak, rubella, cacar air dan beguk
- SK 6.1 dan SP 6.1.1–6.1.2 berdasarkan DSKP KSSR Semakan 2017 PJPK Tahun 5
- Pautan video YouTube
- 25 soalan objektif, maklum balas serta skor bintang
- Animasi litar, kesan bunyi dan pertuturan melalui Web Speech API (jika tersedia pada peranti)
- Panduan penerbitan GitHub Pages

## Jalankan
Buka `index.html` dalam pelayar web moden. Sambungan internet diperlukan untuk membuka video dan panduan GitHub.

## Terbitkan di GitHub Pages
1. Cipta repositori awam baharu di https://github.com/new
2. Muat naik `index.html` ke root repositori dan commit.
3. Pergi ke **Settings → Pages**.
4. Di **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, kemudian **Save**.
5. Tunggu proses selesai. URL lazim: `https://USERNAME.github.io/REPOSITORY/`.

## Nota
- Laman ini tidak diterbitkan secara automatik ke akaun GitHub pengguna. Pengguna perlu memuat naik fail dan mengaktifkan Pages.
- Suara Bahasa Melayu bergantung pada suara yang dipasang pada sistem/pelayar. Jika tiada suara `ms-MY`, pelayar mungkin menggunakan suara lalai.
- Kandungan kesihatan untuk pendidikan sahaja; bukan alat diagnosis. Semak DSKP rasmi dan panduan kesihatan semasa.
